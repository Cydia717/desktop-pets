# 开发记录：0.1.0 动画与交互版

日期：2026-11-04。正式角色仍为用户原创蓝色恐龙，仓库仍为 Cydia717/desktop-pets。

## 本次实现

- 角色拖动、屏幕工作区边界限制、松手/取消/失焦后的停止。
- 单击轻跳，长按 650 ms 摸摸及爱心；拖动后不会误触点击。
- 随机眨眼、闭眼坐姿睡觉、左右走路图集、八方向看向鼠标。
- 闲置 60 秒睡觉；清醒时以 18–40 秒间隔小范围散步，每次 2.2–4 秒、24 DIP/秒。
- 透明区域按 Canvas alpha 命中检测请求点击穿透；按住时固定为可交互。
- 右键菜单：暂停/继续自主活动、回到主屏幕、退出。Esc 退出；Ctrl+Shift+Q 全局应急退出（快捷键注册成功时）。
- 单实例锁，防止重复启动多个宠物。

## 验证状态

本地 TypeScript + Vite 生产构建通过；代码检查无警告；6 项自动化测试全部通过（素材、边界、IPC 来源、拖动停止及睡眠中断散步）。Windows 透明、点击穿透、拖动、不同 DPI 和多显示器仍需原生实机验证。界面浏览器测试不能替代这些验证。

## 已知边界

本版为 2D 动画桌宠，尚无真实 3D 模型、骨骼、重力落地、摔倒恢复、完整情绪系统、系统托盘或开机启动，不能标记为完整 V1.0。图集有生成式造型差异，需继续校准。

## 下一步

验证原生 Windows 交互与资源占用；根据原图反馈修正素材；再分阶段实现完整 3D 工作书并逐项验收。
